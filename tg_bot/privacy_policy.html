ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ И СОГЛАСИЕ НА ОБРАБОТКУ ПЕРСОНАЛЬНЫХ ДАННЫХ

Настоящая Политика конфиденциальности персональных данных (далее — Политика) действует в отношении всей информации, которую Telegram-бот «ДЕЛУ.ВРЕМЯ» (далее — Бот) может получить о пользователе во время использования сервиса.

1. Общие положения

1.1. Используя Бот, пользователь выражает свое безусловное согласие с настоящей Политикой и условиями обработки его персональных данных. В случае несогласия с этими условиями пользователь должен прекратить использование Бота.

1.2. Оператором персональных данных является разработчик проекта «ДЕЛУ.ВРЕМЯ» (далее — Оператор).

2. Категории обрабатываемых персональных данных

Для предоставления функционала Бота (планирования встреч и интеграции с календарем) Оператор может обрабатывать следующие данные пользователя:

  • Идентификационные данные из Telegram: имя пользователя (Username), уникальный идентификационный номер (User ID), имя и фамилия (указанные в профиле).
  • Контент коммуникации: текстовые сообщения, голосовые сообщения и файлы, передаваемые пользователем в разрешенных чатах (для целей последующего распознавания и извлечения деталей встреч).
  • Данные внешних сервисов (Google Calendar): токены доступа к учетной записи Google Calendar пользователя, необходимые исключительно для создания, чтения и управления календарными событиями по поручению пользователя.

3. Цели сбора и обработки персональных данных

3.1 Обработка персональных данных осуществляется исключительно для достижения следующих целей:

  • Предоставление пользователю доступа к функционалу автоматического планирования событий.
  • Распознавание речи (STT) в голосовых сообщениях и извлечение сущностей (дата, время, участники) с помощью языковых моделей (LLM).
  • Интеграция с Google Calendar для автоматического создания и синхронизации событий.
  • Техническая поддержка пользователей и улучшение качества работы сервиса.

4. Условия обработки и передачи данных третьим лицам

4.1. Оператор обеспечивает конфиденциальность персональных данных пользователя.

4.2. Для реализации ключевых функций Бота (распознавание аудио и обработка текста) обезличенные или транзитные фрагменты сообщений могут передаваться сторонним сервисам и API (например, сервисам транскрибации речи и LLM-провайдерам) строго в объеме, необходимом для формирования расписания.

4.3. Передача данных Google Calendar происходит исключительно через официальный протокол Google OAuth 2.0 по прямому поручению пользователя. Оператор не сохраняет пароли от учетных записей Google.

5. Сроки хранения и порядок отзыва согласия

5.1. Персональные данные обрабатываются в течение всего времени использования Бота пользователем.

5.2. Пользователь в любой момент может отозвать свое согласие на обработку персональных данных, отправив запрос в поддержку Бота или выполнив команду полного удаления данных. После этого все данные пользователя подлежат удалению с серверов Оператора.
